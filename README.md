# Synthetique Blog

A modern blogging platform where you can create an account, write and publish posts, and browse content from the community.

Built with **React** and **Vite**, with **Redux** for auth state, **Tailwind CSS** for UI, **Appwrite** for backend (auth, database, and image storage), and **TinyMCE** for rich text editing.

## Features

- User signup, login, and logout
- Create, edit, and delete your own posts
- Rich text editor with image upload
- Browse all published posts on the home feed

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

Fill in your Appwrite and TinyMCE keys in `.env` before running the app.
